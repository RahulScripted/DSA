## 🚀 Getting Started

### Prerequisites

![GCC](https://img.shields.io/badge/GCC-C++17-00599C?style=flat-square&logo=gnu&logoColor=white)
![VS Code](https://img.shields.io/badge/VS_Code-Editor-007ACC?style=flat-square&logo=visualstudiocode&logoColor=white)

### Compile & Run

```bash
# Compile a single file
g++ -std=c++17 -o output filename.cpp

# Run
./output

# Compile with warnings (recommended)
g++ -std=c++17 -Wall -Wextra -o output filename.cpp
```

### Example

```bash
cd "Sorting/Merge Sort"
g++ -std=c++17 -o mergesort IncreasingOrderMergeSort.cpp
./mergesort
```

## 🤝 Contributing

```bash
# 1. Clone the repo
git clone <repo-url>
cd DSA

# 2. Create a topic branch
git checkout -b topic/<topic-name>

# 3. Add your solution
# Follow naming convention: PascalCase.cpp

# 4. Commit with a clear message
git add .
git commit -m "feat(binary-search): add KthSmallestInMatrix"

# 5. Push and open a PR
git push origin topic/<topic-name>
```

**Naming convention:** `PascalCase.cpp` — e.g., `FindTheDuplicateNumber.cpp`

| Rule | Requirement |
|---|---|
| ✅ File naming | `PascalCase.cpp` |
| ✅ Folder placement | Place in the correct topic folder |
| ✅ Code style | Clean, readable, with comments where needed |
| ✅ Compilation | Must compile with `g++ -std=c++17` |
